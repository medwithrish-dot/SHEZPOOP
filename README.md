# 💩 SHEZPOOP — The Legend of Mayk

> *"Behind every great Poopboy stands one questionable Mao Mao Man."*

An award-winning caliber, absurdist, single-page interactive experience celebrating **Shezpoop** (real name: **Mayk**), the chaotic and feared Right-Hand Mao Mao Man to the legendary **Poopboy** (@Xizaterasu).

---

## 🌟 Features & Highlights

1. **The Grand Entrance (Hero)**
   - Massive animated typography with floating poop mascot and avatar integration.
   - Interactive button: `ENTER THE POOPVERSE` with particle shower and smooth scroll.
   - Animated glowing badge: `OFFICIALLY UNHINGED`.
   - Hidden 5-click easter egg revealing Mayk's forbidden knowledge.

2. **Who the Hell is Shezpoop? (Origin)**
   - Dramatic two-column layout with archival photography.
   - Satirical documentary-style lore explaining Mayk's rise to infamy.
   - Badges: `PUBLIC HEALTH CONCERN`, `99.9% SUSPICIOUS`, `MAO MAO AUTHORIZED`.

3. **The Rise of Mayk (Vertical Timeline)**
   - Interactive vertical timeline from `420 BC (Before Commode)` to `The Sacred Chat Epoch`.
   - Embeds authentic historic artifacts including the sacred promise: *"I'll acc make a website for ur poop"*.
   - Clickable cards with secret comedic footnotes.

4. **Shezpoop's Special Powers**
   - 6 Interactive cards with 3D tilt hover effects:
     - The Brown Touch
     - Supreme Mao Mao Energy
     - Emergency Poop Summoning
     - The Legendary Side-Eye
     - Royal Toilet Authority
     - Unexplained Mayk Behaviour
   - Fictional Power Meter dramatically filling to 999% output with sewer danger warning.

5. **The Shezpoop Photo Gallery & Lightbox**
   - Archival photos including Poopboy's Roblox profile (@Xizaterasu) and the sacred pact.
   - Polished inspection lightbox with classified forensics and dismiss controls.

6. **Playable Mini-Game: Catch the Golden Poop**
   - Real, responsive Canvas game with 60 FPS physics.
   - Control the porcelain commode using Left/Right Arrow keys, A/D, mobile drag, or touch buttons.
   - Normal Poop: `+10 pts` | Golden Poop: `+50 pts` | Dangerous Chili: `-20 pts`.
   - 30-second timer with scaling falling speed.
   - Dynamic score popups, particle explosions, and screen shake.
   - Persistent High Score saved via `localStorage`.
   - Secret achievement unlocked for catching 3 golden poops in one run.

7. **The Mao Mao Hall of Fame**
   - Animated count-up metrics: `Toilets Conquered (9,999+)`, `Mao Mao Energy (100%)`, `Times Questioned (47)`, `Poopboy Approval (CLASSIFIED)`, `Lawsuits Evaded (1,337)`.
   - Interactive `TOP SECRET` card that decrypts classified surveillance logs upon click.

8. **The Final Poopolution & Poopstorm**
   - Giant interactive bouncing poop emoji.
   - Button: `UNLEASH THE POOPSTORM` with screen-shaking confetti & emoji explosion.
   - Humorous agency-grade footer.

9. **Surprises, Easter Eggs & Sound FX**
   - **Konami Code (`↑ ↑ ↓ ↓ ← → ← → B A`)**: Triggers `MAO MAO OVERDRIVE` rainbow celebration!
   - **Secret 5-Click Poop**: Opens the Forbidden Knowledge dossier.
   - **Tiny Runner**: A miniature poop occasionally sprints across the bottom of the screen.
   - **Poopboy is Watching**: Stealth notification banners.
   - **Sound Effects**: Procedural Web Audio API sound synthesis (plops, farts, chimes, fanfares) — zero external MP3 dependencies, toggleable in navbar.
   - **Achievements System**: 9 unlockable badges with live notification toasts and drawer modal.

## 🚀 Running the Project Locally

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The website will be live at `http://localhost:5173/`.
